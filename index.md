# Setup Simplified Analytics

Setup Simplified Analytics is a private reporting tool for the owner of the [Setup Simplified YouTube channel](https://www.youtube.com/@setupsimplifiedhq). It uses YouTube API Services to refresh a private Google Sheets dashboard with channel performance data such as views, engagement, retention, traffic sources and subscriber trends.

The channel owner grants read-only access through Google. The tool reads YouTube reports and updates the owner's spreadsheet. It has no YouTube publishing or editing features.
