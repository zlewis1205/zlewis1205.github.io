# Privacy policy

Setup Simplified Analytics uses [YouTube API Services](https://developers.google.com/youtube) to refresh a dashboard for the Setup Simplified channel owner. Google's handling of account data is described in the [Google Privacy Policy](https://policies.google.com/privacy).

## What the integration reads and stores

With the owner's permission, the script reads channel and upload details, including scheduled upload metadata, and reporting data such as views, watch time, engagement, audience retention, traffic sources, thumbnail reach and subscriber changes. It can read estimated revenue when the channel is eligible and the reports are available.

The script uses that data for channel performance reporting in Google Sheets. The dashboard is available to the owner and collaborators the owner authorizes through Sheets. The dashboard does not send YouTube data to this public website. The OAuth grant used for scheduled requests is stored in the owner's Apps Script user settings. The integration does not collect Google passwords.

## Managing access and deleting data

The owner can stop the scheduled refresh in Apps Script and revoke access in [Google Account permissions](https://myaccount.google.com/permissions). The owner can remove imported API data from the dashboard and clear the stored OAuth grant. If access is revoked, remove the associated authorized data promptly. For privacy questions or help with deletion, contact the operator through the [Setup Simplified channel](https://www.youtube.com/@setupsimplifiedhq/about).
